OneFolio API

계좌별 잔고파일을 받아 자산배분과 종목별 손익을 계산해 돌려준다.

Base http://localhost:8080 인증 없음 응답 JSON (UTF-8) 금액 원 (해외도 환산됨)

엔드포인트

헬스체크

GET/health

서버가 살아있는지 확인한다. Render 헬스체크용.

응답 200

{ "status": "ok" }

자산배분 집계

POST/api/portfolio

잔고파일을 하나 이상 받아 통합·분류·집계한 결과를 돌려준다.

요청 — multipart/form-data

필드타입필수설명
files file (반복) 필수 잔고파일. 같은 필드명으로 여러 개를 보낸다. 전체 32MB 이하.
overrides string (JSON) 선택 자동 분류를 덮어쓸 {"종목명": "카테고리"} 매핑.

응답

코드본문상황
200Summary정상
400Errorfiles가 비었거나, overrides가 JSON이 아니거나 모르는 카테고리를 담았을 때
422Error파일은 받았지만 잔고파일 형식이 아닐 때

예시

curl -X POST http://localhost:8080/api/portfolio \
  -F "files=@ISA계좌.xls" \
  -F "files=@연금저축계좌.xls" \
  -F "files=@종합주식계좌.xls" \
  -F 'overrides={"TIGER 미국테크TOP10":"레버리지·테마 ETF"}'
미래에셋은 다운로드 시 선택한 계좌의 종목 상세만 파일에 담는다. 전체 자산을 보려면 계좌별로 받은 파일을 한 번에 모두 올려야 한다. 같은 파일을 두 번 올려도 중복되지 않는다.

에러 형식

모든 에러는 같은 형태로 온다.

{ "error": "설명 메시지" }

Summary

필드타입설명
totalAssetnumber계좌 자산총액의 합. 모든 비중의 분모
categoriesCategory[]카테고리별 집계. 금액 내림차순
holdingsHolding[]종목별 상세. 평가금액 내림차순

Category

필드타입설명
categorystring카테고리명
amountnumber평가금액 합계
weightnumber총자산 대비 비중 (%)

Holding

필드타입설명
namestring상품명
categorystring분류 결과
accountNumberstring소속 계좌번호 (하이픈 제거)
quantitynumber보유수량. 소수점 거래가 있어 정수가 아닐 수 있다
currentPricenumber · null현재가
avgBuyPricenumber · null평균매입가
buyAmountnumber · null매입금액
evalAmountnumber평가금액
profitLossnumber · null평가손익
profitRatenumber · null손익률 (%). -3.21 형태
weightnumber총자산 대비 비중 (%)
같은 종목이 여러 행으로 올 수 있다. 계좌를 나눠 같은 ETF를 들고 있으면 계좌마다 별도 행이다. 종목 단위로 합치려면 name으로 묶어야 한다.

카테고리

category 필드와 overrides 값에 쓰이는 문자열은 다섯 가지뿐이다.

값설명
개별주(국내)국내 상장 주식
개별주(해외)해외 상장 주식
지수 ETF지수를 추종하는 ETF
레버리지·테마 ETF레버리지·인버스·테마형 ETF
현금성예수금, 외화 등 종목으로 잡히지 않는 잔액

우선순위

세 단계로 결정된다. 위쪽이 이긴다.

순위근거결정하는 것
1요청의 overrides전부
2KIS 종목마스터 조회국내/해외, ETF/개별주
3이름 키워드 규칙마스터에 없는 신규 상장 종목 폴백

마스터 조회는 띄어쓰기와 대소문자를 무시한다. 마스터는 "ETF다"까지만 알려주고 그 안에서 지수추종이냐 레버리지·테마냐는 구분하지 않으므로, 이 갈래만 3X, 레버리지, 나스닥100 같은 이름 키워드로 판단한다. 애매한 종목은 overrides로 잡아주면 된다.

현금성 계산

현금성은 별도로 집계하지 않고 총자산에서 종목 평가금액 합을 뺀 나머지다. 예수금은 잔고파일에 행으로 나오지 않고 자산총액에만 반영되기 때문이다. 외화처럼 취득원가가 없는 행도 종목이 아니라 이쪽으로 들어간다.

환경변수

이름기본값설명
PORT8080수신 포트. Render가 주입한다
ALLOWED_ORIGINS(비어있음)CORS 허용 오리진, 쉼표로 구분. 비우면 모두 허용

로컬 실행

cd backend
go run ./cmd/server

배포

배포 시 프론트 도메인을 지정한다.

ALLOWED_ORIGINS=https://onefolio.pages.dev
Render의 Root Directory를 backend로 지정해야 한다. Go 모듈이 저장소 루트가 아니라 하위 디렉토리에 있다.

데이터 보관

서버는 아무것도 저장하지 않는다. 업로드된 잔고파일과 계산 결과는 응답을 보낸 뒤 폐기된다. 보유종목·평단·잔고는 프론트 로컬(IndexedDB)에만 남는다.
