OneFolio API

미래에셋 계좌별 잔고파일을 받아 자산배분과 종목별 손익을 계산해 돌려주는 백엔드 API.

서버는 아무것도 저장하지 않는다. 업로드된 잔고파일과 계산 결과는 응답을 보낸 뒤 폐기된다. 보유종목·평단·잔고는 프론트 로컬(IndexedDB)에만 남는다.

자산배분 집계

POST/api/portfolio

잔고파일을 하나 이상 받아 통합·분류·집계한 결과를 돌려준다. 미래에셋은 다운로드 시 선택한 계좌의 종목 상세만 파일에 담기 때문에, 전체 자산을 보려면 계좌별로 받은 파일을 한 번에 모두 올려야 한다.

요청

Content-Type: multipart/form-data

필드타입필수설명
files file (반복) 필수 잔고파일. 같은 필드명으로 여러 개를 보낸다.
확장자는 .xls지만 실제 내용은 HTML이며, 서버가 알아서 처리한다.
전체 업로드 크기 상한 32MB.
overrides string (JSON) 선택 자동 분류를 덮어쓸 {"종목명": "카테고리"} 매핑.
사용자가 수동 태깅한 결과를 넘기는 용도.
같은 파일을 두 번 올려도 종목이 중복되지 않는다. 계좌는 계좌번호로, 종목은 계좌 + 종목명으로 중복을 제거하며, 겹치면 나중 파일 값이 이긴다.

응답 200

필드타입설명
totalAssetnumber계좌 자산총액의 합. 모든 비중의 분모
categoriesarray카테고리별 집계. 금액 내림차순
holdingsarray종목별 상세. 평가금액 내림차순

categories[]

필드타입설명
categorystring카테고리명 (아래 목록 참고)
amountnumber평가금액 합계
weightnumber총자산 대비 비중 (%)

holdings[]

필드타입설명
namestring상품명
categorystring분류 결과
accountNumberstring소속 계좌번호 (하이픈 제거)
quantitynumber보유수량. 소수점 거래가 있어 정수가 아닐 수 있다
currentPricenumber 또는 null현재가
avgBuyPricenumber 또는 null평균매입가
buyAmountnumber 또는 null매입금액
evalAmountnumber평가금액
profitLossnumber 또는 null평가손익
profitRatenumber 또는 null손익률 (%). -3.21 형태
weightnumber총자산 대비 비중 (%)
같은 종목이 여러 행으로 나올 수 있다. 계좌를 나눠 같은 ETF를 들고 있으면 계좌마다 별도 행으로 온다. 종목 단위로 합치려면 프론트에서 name으로 묶어야 한다.

예시 요청

curl -X POST http://localhost:8080/api/portfolio \
  -F "files=@ISA계좌.xls" \
  -F "files=@연금저축계좌.xls" \
  -F "files=@종합주식계좌.xls" \
  -F 'overrides={"TIGER 미국테크TOP10":"레버리지·테마 ETF"}'

카테고리

category 필드와 overrides 값에 쓰이는 문자열은 다음 다섯 가지뿐이다.

값설명
개별주(국내)국내 상장 주식
개별주(해외)해외 상장 주식
지수 ETF지수를 추종하는 ETF
레버리지·테마 ETF레버리지·인버스·테마형 ETF
현금성예수금, 외화 등 종목으로 잡히지 않는 잔액

분류 우선순위

세 단계로 결정된다. 위쪽이 이긴다.

  1. 사용자 매핑 — 요청의 overrides
  2. 종목마스터 조회 — 종목명으로 국내/해외와 ETF/개별주를 확정한다. 띄어쓰기와 대소문자는 무시한다
  3. 이름 규칙 — 마스터에 없는 신규 상장 종목용 폴백

마스터는 "ETF다"까지만 알려주고 그 안에서 지수추종이냐 레버리지·테마냐는 구분하지 않는다. 이 갈래는 3X, 레버리지, 나스닥100 같은 이름 키워드로 판단하므로 애매한 종목은 overrides로 잡아주면 된다.

현금성 계산

현금성 금액은 별도로 집계하지 않고 총자산에서 종목 평가금액 합을 뺀 나머지다. 예수금은 잔고파일에 행으로 나오지 않고 자산총액에만 반영되기 때문이다. 외화처럼 취득원가가 없는 행도 종목이 아니라 이쪽으로 들어간다.

에러

모든 에러는 같은 형태로 온다.

{ "error": "설명 메시지" }
상태상황
400files 필드가 비었거나, 업로드를 읽지 못했거나, overrides가 JSON이 아니거나 모르는 카테고리를 담고 있을 때
422파일은 받았지만 잔고파일 형식이 아닐 때 (전체 계좌현황 테이블 없음)

로컬 실행:

cd backend
go run ./cmd/server

배포 시 프론트 도메인을 지정한다:

ALLOWED_ORIGINS=https://onefolio.pages.dev
Render의 Root Directory를 backend로 지정해야 한다. Go 모듈이 저장소 루트가 아니라 하위 디렉토리에 있다.
