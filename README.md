# OneFolio

증권 계좌별 잔고파일을 파싱·통합해서 자산 배분(지수/개별주/현금 비중)과 종목별 손익을 보여주는 개인용 대시보드.

## 구조

```
backend/    Go — 잔고파일 파싱 / 통합 / 분류 / 집계
frontend/   React — 파일 업로드 UI, 파이차트, 손익 테이블
```

## ⚠️ 잔고 파일은 절대 커밋하지 말 것

잔고파일에는 계좌번호·보유종목·평단·잔고가 그대로 들어있다.
`.xls` / `.xlsx` / `.csv`는 `.gitignore`로 전면 차단되어 있으며, 파서 테스트에는 **마스킹된 픽스처**(`backend/internal/parser/testdata/*_masked.xls`)만 사용한다.

## 브랜치 규칙

- `feature/*` — 기능 개발
- `fix/*` — 버그 수정
- `chore/*` — 설정·문서·빌드

`main`에는 직접 커밋하지 않는다.
