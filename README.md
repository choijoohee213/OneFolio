# OneFolio

흩어진 증권 계좌를 하나로 모아 자산 배분(지수/개별주/현금 비중)과 종목별 손익을 보여주는 개인용 대시보드.

https://onefolio.choijoohee.workers.dev

## 자산을 넣는 방법

무엇으로 넣든 하나로 통합해서 집계한다. 셋을 섞어 써도 된다.

- **스크린샷** — 증권사 앱 보유종목 화면을 올리면 종목·수량·평단을 자동으로 읽어들인다. 증권사를 가리지 않는다.
- **잔고파일** — 미래에셋 잔고파일(`.xls`)을 올리면 계좌 전체를 한 번에 가져온다.
- **직접 입력** — 종목을 검색해서 수량과 평단을 넣는다.

## 구조

```
backend/    Go — 잔고파일 파싱 / 스크린샷 OCR / 분류 / 집계 / 시세 조회
frontend/   React — 자산 등록 UI, 파이차트, 손익 테이블
```

## ⚠️ 잔고 파일은 절대 커밋하지 말 것

잔고파일에는 계좌번호·보유종목·평단·잔고가 그대로 들어있다.
`.xls` / `.xlsx` / `.csv`는 `.gitignore`로 전면 차단되어 있으며, 파서 테스트에는 **마스킹된 픽스처**(`backend/internal/parser/testdata/*_masked.xls`)만 사용한다.

## 브랜치 규칙

- `feature/*` — 기능 개발
- `fix/*` — 버그 수정
- `chore/*` — 설정·문서·빌드

`main`에는 직접 커밋하지 않는다.
